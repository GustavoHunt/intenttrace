# Security boundaries

This public repository must contain only synthetic evidence and public identifiers. User imports stay in ignored local runtime storage. Live mode sends selected evidence to Cloudflare Workers AI; review the provider's terms before processing confidential material. Never commit real client documents, tokens, private source or chat transcripts.

- Production credentials belong in Cloudflare Workers Secrets. Workers AI and R2 are accessed through bindings, not embedded API keys.
- Local `.dev.vars`, `.env`, generated deployment configuration, Wrangler state and dependency directories are ignored by Git.
- The included scanner flags common credential patterns without printing suspected values. It cannot detect every secret. Review staged changes before publication and enable GitHub secret scanning/push protection where available.
- Server ownership checks protect both HTTP case routes and the Agent protocol. Turnstile does not replace ownership checks.
- Imported evidence and model text are untrusted. Evidence cannot expand the tool allowlist. The local Vite importer uses HTTPS, bounded response sizes, DNS answers validated and pinned for each redirect, no credentials/cookies, and blocked private/special IPs. Imported HTML is displayed as text. During an explicitly initiated live assessment, a separate anonymous Cloudflare Browser Run session may execute public page scripts to observe rendered DOM. Browser guardrails restrict exact supplied hosts plus common CDN domains; request interception permits GET only, validates public DNS, and blocks media, fonts, images and action-like URLs. Browser DNS cannot be pinned by application code, unlike Node intake; public DNS checks are a defense in addition to provider isolation, not a claim of a universal network sandbox. No saved user browser profile, sign-in, local file, or arbitrary repository execution is available.
- Collection is bounded to ten pages, two link-selection rounds and 120 seconds in targeted mode, or thirty pages, six rounds and 300 seconds in expanded mode. Browser observations are extracted in a CDP isolated world so page scripts cannot replace the bounding primitives. Each observation is capped at 256 KiB of encoded UTF-8, with an 8 MiB collection budget. Case evidence bodies are capped at 16 MiB and workflow snapshots at 20 MiB; stored-body metadata and streamed bytes are checked before decoding and hashing. Server-HTML checks use a separate anonymous HTTP read capped at 200,000 bytes, parsed without executing scripts, rather than the original navigation response. Truncation and unavailable reads remain explicit. The model selects IDs from observed candidate URLs; it cannot provide executable code or arbitrary fetch targets. Service failures and omitted pages remain visible. Hashes, source URLs and timestamps bind quotations to the collected record. A quote-match check rejects invented text and source IDs, but does not independently prove a model's interpretation. Analytics, historical delivery and authorship require separate evidence.
- Local development requires localhost and the server binds to 127.0.0.1. A random local signing key replaces the public Turnstile/secret setup. Never expose this configuration through a public proxy or tunnel.
- File import limits are 5 MiB and 300,000 extracted text characters; PDFs are limited to 80 pages. DOCX extraction includes document text, not macros, embedded objects or images. Original binary and extracted-text hashes describe different bytes. CLEF receives bounded excerpts; omitted material remains unknown.
- Hash validation detects changed bytes. It does not establish the author, provenance or accuracy of imported evidence.
- The application disables AI Gateway content logging per request and logs operation metadata only. Cloudflare service telemetry and retention still need an operator review before handling anything beyond synthetic data.
- Model quotas are atomic reservations. Request-rate limits are an additional abuse control and are not an account-wide bill cap.
- The OAuth installer requests account-level scopes; installation-name restrictions are enforced by application code. Its AES-GCM credential vault has a 30-minute lifetime, single-use OAuth state, PKCE, same-origin writes and a request limit. It revokes access on successful completion or explicit disconnect; expiration attempts provider revocation before deleting its local copy. A provider outage can prevent confirmed revocation.
- The installer does not log raw requests. Use warning-level local development logs so callback URLs containing authorization codes are not printed. Do not enable request logging or analytics on OAuth callback routes without redaction.
- `/api/install-check` requires the installed application's generated signing secret and only renders fixed synthetic HTML. It accepts no URL or arbitrary program. Its result is cached in private R2 and scoped to the packaged release.
- Operator-only scope repair accepts an administration token through an environment variable or a local ignored file, never a command-line token value. Revoke the temporary OAuth Client Write token after configuring the client.

If a credential is ever exposed, revoke/rotate it in its issuing service first; deleting a file or rewriting Git history does not revoke access. Do not paste suspected credentials into a public issue. This project does not promise a staffed security response service.


## Private evidence connections

Connection APIs require the existing same-origin, session-owned API boundary. At most six connections are held in AES-GCM encrypted form in the session Durable Object; the encryption key stays in its server storage and expires with the 24-hour session. This protects against accidental persistence/log disclosure, not a compromised server or administrator with storage access. Credentials are excluded from case snapshots, R2 artifacts, reports and model inputs. Disconnect removes the credential from future collections; previously collected evidence remains until case expiry/deletion, and an already-started read can complete.

Cloudflare Access headers are injected only for the configured exact HTTPS origin; inherited authorization/service-token headers are stripped from every other request. Browser browsing remains GET-only, with public-DNS checks and approved-host navigation. Accordion probes are bounded to four non-form controls with expanded state and controlled panels; all network requests are blocked during those interactions. Provider APIs use fixed endpoints and fixed aggregate read queries, disallow redirects, bound responses to 1 MiB and sanitize provider failures. Tokens must already have appropriate read-only permissions; the application does not create tokens or enforce a provider's credential scope externally. Google access-token expiry is reported as a connection problem, never failed delivery.

Observed page bodies use R2-backed storage manifests with SHA-256 verification on hydration/download. Imports remain supplied evidence regardless of claimed provenance. Synthetic evaluation endpoints accept fixture IDs only and use the same session settings, rate limits and AI budgets as normal assessment.
